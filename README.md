# КзБлеск CRM

Полноценная система приёма звонков и договоров: реальная база данных PostgreSQL,
пароли захешированы (bcrypt), сессии — через JWT в httpOnly-cookie.

Роли:
- **admin** — создаёт договоры, назначает курьеров, видит карту клиента, управляет сотрудниками.
- **courier** — видит только назначенные ему заявки (статус "Забор" и "Доставка") и может
  только двигать статус своей заявки. Цены, адреса других клиентов и список клиентов ему недоступны
  — это проверяется на сервере (в API), а не просто скрыто в интерфейсе.

## Структура проекта

```
kzblesk-crm/
  schema.sql          -- SQL-схема базы данных
  src/
    server.js          -- точка входа
    db.js               -- подключение к Postgres
    auth.js              -- проверка JWT и ролей
    routes.auth.js         -- вход/выход
    routes.contracts.js     -- договоры (с разграничением прав)
    routes.clients.js        -- карта клиента (только admin)
    routes.users.js           -- управление сотрудниками (только admin)
    seed-admin.js               -- скрипт создания первого админа
  public/
    index.html    -- страница входа
    admin.html    -- панель администратора
    courier.html  -- панель курьера
    style.css / common.js
```

## Запуск локально

1. Установите PostgreSQL и Node.js (18+).
2. Создайте базу данных:
   ```
   createdb kzblesk
   psql kzblesk -f schema.sql
   ```
3. Скопируйте `.env.example` в `.env` и укажите свои данные подключения.
4. Установите зависимости и создайте первого администратора:
   ```
   npm install
   node src/seed-admin.js admin@example.com ваш_пароль "Имя Фамилия"
   ```
5. Запустите сервер:
   ```
   node src/server.js
   ```
6. Откройте http://localhost:3000 — войдите под созданным админом.
   Через панель "Сотрудники" создайте учётки для курьеров.

## Деплой (чтобы сайт был доступен всем)

Нужны две вещи: работающий Postgres в интернете и хостинг для Node.js-сервера.
Проще всего:

1. **База данных:** создайте бесплатный проект на [neon.tech](https://neon.tech) или
   [supabase.com](https://supabase.com) (просто база Postgres, без их доп. функций) —
   получите `DATABASE_URL` и выполните в их SQL-редакторе содержимое `schema.sql`.
2. **Сервер:** задеплойте эту папку на [Render.com](https://render.com) или
   [Railway.app](https://railway.app) (оба поддерживают Node.js "из коробки"),
   указав переменные окружения `DATABASE_URL` и `JWT_SECRET` (сгенерируйте случайную длинную строку).
3. После деплоя один раз выполните `node src/seed-admin.js ...` (через консоль хостинга)
   чтобы создать первого админа.
4. Привяжите свой домен (например, тот же kzblesk...) в настройках хостинга.

## Важно перед реальным использованием

- Смените `JWT_SECRET` на случайную строку (не используйте значение из `.env.example`).
- Все пароли сотрудников должны быть надёжными (минимум 6 символов, лучше больше).
- Регулярно делайте резервную копию базы (`pg_dump`).
